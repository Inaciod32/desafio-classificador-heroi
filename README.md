# Desafio Classificador de Nível de Herói

Projeto desenvolvido para o desafio de Lógica de Programação da DIO.

## Objetivo

Criar um programa que armazene o nome e a quantidade de experiência (XP) de um herói e classifique o seu nível de acordo com a quantidade de XP.

## Conceitos utilizados

- Variáveis
- Operadores
- Laço de repetição `for`
- Estruturas condicionais `if`, `else if` e `else`
- Template literals

## Classificação

| XP | Nível |
| --- | --- |
| Até 1.000 | Ferro |
| 1.001 a 2.000 | Bronze |
| 2.001 a 5.000 | Prata |
| 5.001 a 7.000 | Ouro |
| 7.001 a 8.000 | Platina |
| 8.001 a 9.000 | Ascendente |
| 9.001 a 10.000 | Imortal |
| A partir de 10.001 | Radiante |

## Execução

Com Node.js instalado, execute:

```bash
node index.js
```

Saída esperada para os valores atuais:

```text
O Herói de nome Davi está no nível de Platina
```
